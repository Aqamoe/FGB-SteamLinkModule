## 环境

| 头显 | Meta Quest（带眼动/面捕的型号，记录固件版本） |
| 串流 | Steam Link 头显端 + PC 端（记录版本号） |
| 系统 | Windows 10 / 11 x64 |
| 宿主 | FaceGaze Bridge（记录版本号） |

## 步骤

- [ ] PC 上关闭 VRCFT 及其它占用 9015 的程序
- [ ] 头显 Steam Link 设置开启「高级设置」→「启用 OSC」「分享眼动数据…」「分享面捕数据…」，端口 9015
- [ ] 用 Steam Link 串流本机
- [ ] FGB「模块库 → 原生模块」安装 `steamlink-<版本>.zip`
- [ ] 「模块」页把 Steam Link 设为启动，重启引擎
- [ ] 模块卡片显示活跃

## 观察项

- [ ] 注视：看房间正前方 → 方向接近 (0,0,-1)；看左/右/上/下 → 方向随动且**不反**（坐标系假设验证）
- [ ] 注视时效：头显里关掉「分享眼动数据」但保留面捕 → 500ms 内方向位消失，表情仍继续
- [ ] 眨眼 → 对应侧睁眼度下降，左右眼独立
- [ ] 张嘴 → `JawOpen`；抿嘴 → `MouthClosed`；微笑 → `MouthCornerPull*`
- [ ] 挑眉 / 皱眉 / 鼓腮 / 伸舌均有响应
- [ ] bundle 完整性：网络差时表情不应长时间停留旧值或抖动异常
- [ ] 关闭头显眼动/面捕分享 → 10 秒内卡片给出「已 N 秒没有数据」
- [ ] 恢复后自动回到活跃
